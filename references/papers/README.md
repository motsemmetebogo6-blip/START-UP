# Shared folder for downloaded papers

Save each paper as `R-xx_FirstAuthor_Year.pdf` (e.g. `R-13_McDougall_2007.pdf`).
The full list of papers, links, what we took from each and who checks it is in
`docs/05_Literature_and_Evidence_Map.md`. After checking a paper against our values,
the Project Leader updates its status in `references/REFERENCES.md` from AB (abstract only)
to FT (full text checked).
